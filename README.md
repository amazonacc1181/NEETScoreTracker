# NEET Score Tracker
Native Android app to save NEET mock-test scores. Marking: +4 correct, -1 wrong. Physics and Chemistry max 45 questions each; Biology max 90. Results are stored locally on the device.

GitHub Actions builds a debug APK on every push to main or via Actions > Build NEET Score Tracker APK > Run workflow. Download the artifact named NEET-Score-Tracker-debug-apk from a successful run and unzip it to get app-debug.apk.
